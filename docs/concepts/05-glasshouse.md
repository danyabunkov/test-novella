# 05 - Glasshouse

Genre: hidden-object with light narrative. Engine target: Godot.

Hook: In an abandoned greenhouse, every found object is a fragment of someone's life.

Prototype mechanic: find listed objects in a placeholder greenhouse scene.

Production notes:
- Detailed greenhouse backgrounds are ideal local image-generation tasks.
- Needs item hitbox annotation tooling later.
- Main risk is fairness: hidden objects must be readable, not arbitrary.

Prototype done when:
- A target list is shown.
- Clickable objects can be found.
- Completion unlocks a short story fragment.
