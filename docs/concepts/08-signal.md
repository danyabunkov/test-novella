# 08 - Signal

Genre: mystery VN with investigation mechanics. Final engine target: Ren'Py with custom screens.

Hook: A radio operator catches a transmission that should not exist. You have seven nights to learn who is speaking.

Prototype mechanic: evidence-linking deduction board.

Production notes:
- Retro techno-noir art style.
- Evidence objects, radio room backgrounds, and signal visions are local art tasks.
- Main risk is deduction fairness.

Prototype done when:
- Evidence pairs can be linked.
- Correct deductions advance the night.
- Wrong deductions increase paranoia.
