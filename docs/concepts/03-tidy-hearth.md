# 03 - Tidy Hearth

Genre: cozy organizing puzzle. Engine target: Godot.

Hook: Tidy other people's homes and discover their stories through objects.

Prototype mechanic: sort a small set of household objects by acceptable grouping rules.

Production notes:
- Warm hand-drawn cozy style.
- Style LoRA is more important than character LoRA.
- Multiple valid solutions are a core design challenge.

Prototype done when:
- Objects can be cycled between groups.
- At least one valid arrangement completes the scene.
