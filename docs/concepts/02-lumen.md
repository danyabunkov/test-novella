# 02 - Lumen

Genre: light and mirror puzzle. Engine target: Godot.

Hook: Guide light through darkness; every beam draws the solution.

Prototype mechanic: rotate a small set of mirrors/prisms until a beam path reaches its target.

Production notes:
- Dark minimalist chambers with neon accents.
- Later systems: RGB splitting, colored gates, lenses, hints.
- Core risk is teaching the difficulty curve without a wall.

Prototype done when:
- Mirror states can be toggled.
- Beam status changes from blocked to solved.
- One completion state is visible.
